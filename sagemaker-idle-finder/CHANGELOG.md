# Changelog

All notable changes to `sagemaker-idle-finder` are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-23

First release.

### Added

#### Scanning

- Lists every endpoint in one or more regions, paginated, and describes each one along with
  its endpoint config to recover instance type, instance count and serverless settings.
- Reads Application Auto Scaling scalable targets for both the variant dimension and the
  inference-component dimension. A registered target with a minimum capacity of zero means
  the variant can already scale to zero, so it is never reported as idle waste.
- `--regions` takes a comma-separated list or `all`; the default is the caller's configured
  region, because an account-wide sweep is not what someone expects from a command they
  just typed.
- A region that fails is reported alongside the findings rather than ending the scan.

#### Measuring

- Sums the `Invocations` metric hourly over a configurable lookback, default 14 days,
  batched into `GetMetricData` calls sized against both documented quotas — at most 500
  queries and 100,800 datapoints per call.
- A metric CloudWatch answers with no data is kept distinct from one it answers with a
  measured zero, so a missing metric cannot be mistaken for an idle endpoint.
- Throttling is retried with exponential backoff.

#### Judging

- Classifies each variant as `idle`, `underused`, `healthy`, `not_applicable`, `too_new` or
  `not_billing`, in an order where the first thing that applies wins.
- An endpoint that existed for less than 80% of the window is `too_new` rather than idle.
- Endpoints that are `Creating`, `Failed` or otherwise not serving are not billed for
  instances and are reported as such.

#### Costing

- Estimates monthly cost and waste from a bundled `prices.yaml` covering 37 regions,
  overridable with `--prices` for negotiated rates. Every figure is labelled an estimate in
  the table, the JSON and the CSV.
- An idle variant wastes its whole cost; an underused one wastes only the instances its
  traffic does not justify.
- Where there is no surplus instance to remove, the waste is reported as **unknown rather
  than zero**: the cost is real, but recovering it means changing how the model is served,
  which this tool cannot cost on its own. The total then says it is a floor and names the
  findings it could not price.
- A price the file does not contain produces a dash and a stated reason, never a silent
  zero.
- `--serverless-seconds` and `--serverless-memory-gb` cost a move to serverless from
  assumptions the caller supplies, since neither can be read from AWS. They must be given
  together: half of them would mean the tool guessing the other half.

#### Recommending

- Names one remedy per finding — delete, move to serverless, move to async with
  scale-to-zero, or reduce the instance count — with the evidence it rests on.
- Accelerated instance families are never proposed for serverless, which has no GPU.

#### Output

- A table sorted by estimated waste with a total, plus `--output json` and `--output csv`,
  all rendered from the same objects so they cannot drift apart.
- The table adapts to the terminal width, dropping the columns that can be recovered from
  `--explain` or the JSON, and saying which ones it dropped. The waste figure and the
  remedy are never the ones dropped.
- `--explain` prints the evidence behind each finding; `--all` includes healthy and
  not-applicable variants.
- Exit codes: 0 nothing wasteful, 1 findings, 2 usage error, 3 unusable data file, 4 the
  scan could not complete.

#### Data

- `prices.yaml` is generated by `scripts/fetch_prices.py` from the AWS Price List bulk API
  and carries AWS's own publication date.
- `policy.yaml` holds everything else. An AWS fact must carry a `source` URL and a
  judgement call must carry a `rationale`, or loading fails. There are no bare numbers in
  the code for either.
- Verified 2026-09-23.

### Security

- **The tool is read-only.** It calls `sagemaker:ListEndpoints`, `DescribeEndpoint` and
  `DescribeEndpointConfig`, `cloudwatch:GetMetricData` and
  `application-autoscaling:DescribeScalableTargets`, and nothing else.
- The allowlist is enforced at runtime by a wrapper around every client, including each
  page of a paginated call, rather than only by review. Anything else raises before it
  reaches the network.
- `sagemaker-idle-finder policy` generates the minimal IAM document from that same
  allowlist, so the documentation and the enforcement cannot drift apart.
- Tests attempt write operations through the guard and assert they are refused and never
  reach the client; CI additionally rejects any write-shaped call appearing in `src/`.
