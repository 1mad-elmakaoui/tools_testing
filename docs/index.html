tools-aws

Small, focused command-line tools for working with AWS. Each one is its own package, installable on its own.

Read-only by default · nothing here calls AWS to run

sagemaker-inference-picker

Describe a workload and get the right Amazon SageMaker inference option, with the specific documented limit that ruled out each of the others. Chooses between real-time endpoints, serverless inference, asynchronous inference and batch transform.

Open the picker →

dqdl-gen

Profiles a CSV or Parquet file and generates a starter AWS Glue Data Quality ruleset in DQDL, with every rule carrying a comment stating the evidence it came from. Rule types are verified against AWS's own DQDL parser. A command-line tool, with no web version.

On GitHub →

What these have in common

  • No tool calls an API that creates, modifies or deletes anything.
  • Every AWS limit they rely on is stored with the documentation page it was verified against and the date it was checked.
  • The claims in the documentation are enforced by tests, so the build fails when one stops being true.
